# Materials page UI audit — follow-up

All four findings from the 2026-10-06 audit have been addressed. The restored outer container and original banner are preserved.

1. **HIGH — Contrast fixed (R-25).** Dark-theme secondary text inside the inventory table now uses the higher-contrast ledger muted color. The batch code's reduced opacity is removed. Browser-computed text color is rgb(174,187,177) over the dark code-cell surface rgb(17,22,20), exceeding 4.5:1.

2. **LOW — Scroll path fixed (R-05; C-3).** On desktop, the Materials container grows with its content and no longer scrolls independently. The document scroll reaches the unchanged 507px-high table viewport; its horizontal scrollbar is now near the bottom of the page rather than below a clipped inner page. The table retains its own vertical and horizontal scrolling.

3. **LOW — Stock and price columns moved forward and narrowed (R-05; C-3).** Table order is now No., Foto, Kode, Nama, Stok, Harga Masuk, Estimasi Nilai, then category/supplier/warehouse/date/actions. The narrow stock header wraps onto multiple lines to avoid extending beneath the sticky Nama column. Header and body still have 12 matching columns.
